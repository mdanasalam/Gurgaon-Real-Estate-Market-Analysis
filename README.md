# Gurgaon Real Estate Market Analysis

## Project Overview

This project focuses on analyzing residential real estate properties across different localities in Gurgaon (Gurugram), India, using Python.

The objective is to explore property pricing patterns, identify premium localities, and generate data-driven insights that can help buyers, investors, and developers make informed decisions.

## Dataset

- Dataset: Gurgaon Real Estate Dataset
- Records: 19,515 property listings (original dataset)
- Domain: Residential Real Estate

## Tools & Technologies

- Python
- JupyterLab
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Workflow

1. Data Loading and Understanding
2. Data Cleaning and Preparation
3. Exploratory Data Analysis (EDA)
4. Business Question Analysis
5. Data Visualization
6. Key Insights Summary

## Business Questions

1. Which is the costliest flat in the dataset?
2. Which locality has the highest average price?
3. Which locality has the highest rate per square foot?
4. Do ready-to-move properties cost more than under-construction properties?
5. Do RERA-approved properties command a price premium?
6. How does area impact property price?
7. Which BHK configuration is the most expensive on average?
8. Which property type is the costliest?
9. Do certain builders consistently price higher?
10. Are larger homes always more expensive per square foot?
